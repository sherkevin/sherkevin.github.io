Principles

  • Define the failure mode before choosing a model or system design.
  • Design fair evaluation before claiming a method works.
  • Complex methods need stopping conditions and rollback paths.
  • LLM applications depend on evidence, constraints, feedback, and controllability.

Thoughts

Feedback will move from streaming to non-Euclidean graph structure.

Streaming feedback has been the core paradigm of past systems: the most natural and the easiest to collect. The next breakthrough is more likely to happen on non-Euclidean, graph-structured feedback. Just as linear superposition perturbs a space nonlinearly through an activation function, non-Euclidean feedback should emerge from streaming feedback via an activation-like perturbation — a perturbation that is essentially a low-dimensional imitation of a dimension-lifting operation.

Memory is a perceptual snapshot of the world; rebuild it at use time.

Memory is a perception-based store of the world. Being finite, it can never truly capture the world and only keeps the slices useful for the current topic; and because the world keeps changing, memory is always going stale. The best approach is not to reuse old memory directly, but to rebuild from the current world at the moment of use.

Intelligence is compression; higher intelligence is reconstruction.

Compression makes the world representable. Decompression unfolds a representation. Reconstruction asks a system to recover structure from fragments, which reflects a deeper understanding of the world.

Memory, tools, and environment are different things.

LLM + memory resembles a brain; tools resemble a body; environment is the world. Memory stores reflection and compressed experience. Environment stores code, data, documents, collaboration context, and concrete artifacts.

Attention is the core of human-AI collaboration.

When building context, humans decide what matters and what can be ignored. This act of attention separates effective collaboration from blind automation.

Frequency shapes memory; value drives reflection.

Models learn general frequency patterns, while personal memory is shaped by the specific frequency of an individual's world. Valuable events trigger reflection, which is an iterative compression of high-value samples.

AI coding is entropy control and minimal change.

Code is an artifact deposited into the environment. Good AI coding is not large-scale generation; it is the smallest necessary change after understanding the project structure, keeping the system readable, maintainable, and reversible.

Frequency is link; link is knowledge.

Everything is frequency. Human language and all languages are frequency; memory is frequency too. Frequency makes objects co-occur, co-occurrence builds links, links produce knowledge, and knowledge produces wisdom. Frequency also discriminates: it separates 0 from 1, and relevant from irrelevant.

What matters is the difference between states.

The world changes continuously; what matters is always the difference between the current state and the previous one. Memory is a snapshot of the world and is therefore always stale; perception is always stale.

A memory module activates part of the base model.

Memory is the result of item recurrence: memory is the model, and the model is memory. An LLM learns the frequency of the world, which is why it is a base model. Forgetting is the bias between the frequency world of a session and the frequency world of the LLM. Information is stale the moment it is produced, so memory is a reconstruction of information, and it is stale the moment it is produced.

Sphere model: frequency similarity stacked on the base world.

Re-examine the relation between vector similarity and frequency: build a frequency-similarity model per session and stack it on the base frequency world as a non-invasive memory module. The key quantities are surprise (peaks), movement speed, and arousal.

Dream: ingest the day and rebuild memory.

Dreaming ingests the day's information and rebuilds current memory: deleting the unnecessary and linking new memory to existing memory. When the intuitive side dominates, wandering ranges wider and finds hidden, non-co-occurrence relations; rational (frequency, semantic) and intuitive (felt similarity, deep similarity) wandering combine near and far.

Three routes to real-time LLM memory.

Zipper KV cache (hologram); causal graphs; bionic layering: active forgetting, passive induction, dream.

Fast and slow thinking are the neural-symbolic combination.

In neural-symbolic intelligence, the neural side is deep learning and intuition; the symbolic side is reasoning and causality. The first is fast thinking: intuitive and quick but without logic. The second is slow thinking: complex but logical, inferential, and derivable.

Three levels of reflecting reality.

Association, intervention, counterfactual. Nearly all current models sit at the association level. Reinforcement learning sits at intervention: an action that actively changes the world. Counterfactual is the higher level: if an earlier action or decision had been different, what would change now? Answering that is what it means to truly understand causation.

Self-evolving agents: value comes from others' evaluations.

Different agents form a network like an ant colony, but with division of labor: each agent grows more familiar with certain task types through the tasks it touches. Each agent carries a vector label for what it is good at, produced by others' evaluations of it: my value is not decided by me but by how others see me. Once the network runs, no dispatcher is needed: each agent decides whether a task suits it, does it if so, and passes it on otherwise.

GAN-style training injects expert attributes.

Training with a GAN can grant professional attributes: the discriminator can be designed as a domain expert judge, so training only the judge plugs expert knowledge into any pre-trained model. This simulates human-LLM interaction with the human replaced by an LLM; because that LLM is more specialized, a small LLM can still be deep. Joint agent training can use the same GAN pattern: task board, communication board, consensus board.

The cost of division of labor and the necessity of collaboration.

The gap between engineering and algorithms is wider than the gap between product and engineering. It is exactly this information asymmetry that makes AI deployment hard: the downside of division of labor and the necessity of collaboration, the same thing as multi-agent coordination. The lesson: an agent must know what it can do, and more importantly what it cannot do and who can help with it.

A unified measure: align space and time perception.

Give every agent a standard-measure middleware that aligns space and time perception.

Let the LLM state its own shortcomings.

Let the LLM say its own shortcomings, and say what it wants.

One Own Rec: return recommendation control to the user.

Tell the app what I want to see, how, and when, instead of letting the recsys guess. This differs essentially from search: search is personalized but still needs your search words; recommendation should discover what you never searched for. What is given to the recsys is not keywords but a coarse intent. Current app recommendation has two problems: memory too heavy, locking onto learned interests while user interests drift; communication too light, receiving only binary feedback that takes many operations to correct.

The post-training paradigm is shifting.

From "train one large model" to "train several experts, then distill and merge": math, code, and agent experts each get specialized RL, then OPD / MOPD compresses the capabilities back into a unified model. On-policy distillation becomes an efficient route beside RL, with the teacher giving dense per-token feedback. Test-time compute becomes a new capability direction. RLVR shifts from stacking rollouts to training well. SFT is no longer merely a warm start for RL. Good data cannot yet be replaced by algorithms.

Post-training perhaps should not be QA-shaped.

Why is fine-tuning all QA-shaped; should it not be pair-shaped? An important reason LLMs hit an upper bound is that they have used up the world's data; further gains require better, deeper use of data.

Generation and judgment differ in complexity; they can spiral upward.

Generation and judgment are tasks of entirely different complexity; the gap between them can drive a spiral of improvement.

The four components of RL and their conversion.

Policy, perception, world knowledge, value function. Perception converts into value function after a point: the former is short-term memory, the latter long-term. Value function is a decomposition of the final target; being able to value the next action means being able to decompose the task. Policy judges by value function: it may follow high value entirely, but must also explore; policy is that balance.

A benchmark is the loss function of the new era.

A good benchmark is interpretable and is a slice of the world: project the world onto it and improve the agent on the concrete task. Agent capability spans reasoning, memory, and tool use; the domain topic is the key; fine-grained scoring rules serve as capability metrics; scores should not be too good, leaving room for self-improvement. Scoring must be repeatable and comparable, which rules out llm-judge first; signals should be dense and continuous, which requires structured agent outputs. Cheating means calling a tool that directly yields the answer to bypass multi-step reasoning; writing the answer from memory is not cheating, because memory is itself part of agent capability.

RecSys 2026 accepted · independent first author

Beyond Passive Preference Inference: User-Governed Preference Memory

A position paper that makes preference governance a first-class problem: each preference record carries provenance, scope, lifecycle, confidence, and disclosure policy, and the system chooses among ask / recommend / wait / abstain while users can inspect, pause, correct, and revoke.

Position paper; verifiable artifacts are the PreferenceMemoryRecord v0 schema, its validator, and an executable agenda — no user study or online A/B.

AAAI under review · independent first author

Holon: Organ-Tree Self-Evolution for Single LLM Agents

A persistent single agent grows reusable organ states without breaking served queries: capabilities form a single-parent Organ State Tree of (scope, executable delta, statistics); reads use a fast path, while persistent edits take an auditable, rollbackable slow path gated by Legal / Mature / Guard / Gain-over-NoOp and committed atomically at request boundaries.

Method contract is design-locked; end-stage results are pending, and older 906-task numbers from a different setup are not used as current results.

AAAI under review · independent first author

Belief Coherence via Trace Monoid Algebra

Instead of textual consensus, this work protects the auditable chain evidence-version → belief → external effect: reads get receipts, superseded sources trigger a mutation closure with per-object revalidation, and commits verify the full evidence-version set, scope epoch, and content fingerprint before any external effect, using idempotency keys to avoid duplicates.

Contract locked and preregistration frozen; the real-evidence stage is pending, so no current-protocol result numbers are reported.

EMNLP under review · independent first author

Earning Roles from Evidence in Multi-Agent Reasoning

Roles emerge from audited contributions rather than fixed personas: agents submit artifact-backed claims, a 7-dimensional persona is updated from accepted work, rework, and timeliness, and later delegation uses this evidence within one-hop, budget, and permission limits.

Method and reported numbers are paper-reported; the full framework source is not reproduced locally, so no open-source or local-run claim is made.

AAAI under review · independent first author

CHORD: Calibrating Hallucinations via Object-Resonant Decoding in MLLMs

Object-grounded decoding for hallucination calibration with visual anchors, late-layer attention, and short-horizon rollout.

Manuscript withheld during double-blind review. Public summary only.

RecSys under review · independent first author

Typed Score Corrections for Frozen Alignment

Typed post-scoring correction for relation collapse in frozen text-to-CF alignment, where semantic similarity does not always imply behavioral substitutability.
